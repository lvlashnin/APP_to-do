## ⚙️ Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/en/download/) and `npm` (or `yarn`) installed.

### Installation

1.  **Clone the repository**

    ```sh
    git clone https://github.com/lvlashnin/APP_to-do.git
    ```

2.  **Navigate to the project directory**

    ```sh
    cd APP_to-do
    ```

3.  **Install dependencies**
    ```sh
    npm install
    ```

### Usage

To run the application in development mode:

```sh
npm run dev
```

Open http://localhost:5173/ (or your specified port) to view it in the browser.
